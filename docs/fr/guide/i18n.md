# Internationalisation

La bibliothèque de composants fournit des packs de texte intégrés pour 10 langues
et permet à l'application hôte d'enregistrer des langues personnalisées. Le
mécanisme reflète la sémantique du `LhLocale` de la lignée web (`@lh-ui/share`)
et est structurellement identique à la couche de thème `LhColors` d'iOS.

## Couverture des langues

| Code | Langue | Remarques |
| --- | --- | --- |
| `zh-CN` | 简体中文 | Langue par défaut |
| `zh-TW` | 繁體中文 | |
| `en-US` | English | |
| `ja-JP` | 日本語 | |
| `ko-KR` | 한국어 | |
| `de-DE` | Deutsch | Exécution uniquement (les 9 langues du site de docs excluent l'allemand) |
| `fr-FR` | Français | |
| `es` | Español | |
| `ar` | العربية | RTL ; `LhTheme` injecte `\.locale` et la disposition s'inverse automatiquement |
| `ru` | Русский | |

> Les codes correspondent au caractère près à `LH_LANGUAGE_CONST` de la lignée
> web `lh-ui-share` ; les valeurs zh-CN de confirmation/annulation proviennent de
> `specs/*.json` (`"确认"` / `"取消"`, R-n5).

## Périmètre (important)

`LhTexts` ne porte que les chaînes intégrées **propres à la bibliothèque** :

- Le texte par défaut des boutons de confirmation/annulation de Dialog / Picker (lorsque `confirmText` / `cancelText` vaut `nil`)
- Les étiquettes d'accessibilité de Loading / Switch, ainsi que le repli
  d'accessibilité de Input / Textarea en l'absence de placeholder

La localisation des textes fournis par l'appelant (`title` / `content` /
`label` / `options` …) relève de la **responsabilité de l'application hôte** :
ces chaînes sont produites par le métier et la bibliothèque ne les gère pas.

## Changer de langue

```swift
// Changement global : LhTheme détient le singleton via @ObservedObject,
// le changement re-rend donc tout l'arbre
LhLocale.shared.setLocale("en-US")

// Code de langue courant
LhLocale.shared.current  // "en-US"
```

`LhTheme` injecte automatiquement le pack courant dans `Environment(\.lhTexts)`
et pilote `\.locale` (ar passe en RTL automatiquement). Les langues non
enregistrées replient sur le **contenu du pack chinois simplifié**
(comme la lignée web).

## Langues personnalisées

```swift
let vietnamese = LhTexts(
  dialogConfirm: "Xác nhận", dialogCancel: "Hủy",
  pickerConfirm: "Xác nhận", pickerCancel: "Hủy",
  loadingLabel: "Đang tải", switchLabel: "Công tắc",
  inputLabelFallback: "Trường văn bản",
  textareaLabelFallback: "Trường văn bản nhiều dòng"
)

LhLocale.shared.register("vi", pack: vietnamese)
LhLocale.shared.setLocale("vi")
```

Les packs enregistrés via `register` **masquent le registre intégré** (les packs
intégrés ne sont jamais écrasés) ; si la langue enregistrée est la langue
courante, l'application est immédiate.

## LhTexts

```swift
public struct LhTexts: Equatable, Sendable {
  public let dialogConfirm: String   // "确认" / "OK" / "確定" …
  public let dialogCancel: String
  public let pickerConfirm: String
  public let pickerCancel: String
  public let loadingLabel: String    // étiquette d'accessibilité
  public let switchLabel: String
  public let inputLabelFallback: String
  public let textareaLabelFallback: String
}

public let ZhCnLhTexts = LhTexts(dialogConfirm: "确认", /* … */)
public let EnUsLhTexts = LhTexts(dialogConfirm: "Confirm", /* … */)
// … ZhTw / JaJp / KoKr / DeDe / FrFr / Es / Ar / Ru
```

L'initialiseur est public : les tests unitaires peuvent construire des packs
directement. Sans conteneur `LhTheme`, le defaultValue de la clé Environment
replie sur `ZhCnLhTexts` (chinois par défaut, mirroir du « clair par défaut »
de la couche de thème).

## Relation avec la couche de thème

| | Couleurs | Textes |
| --- | --- | --- |
| Type valeur | `LhColors` | `LhTexts` |
| Préréglages | `LightLhColors` / `DarkLhColors` | `ZhCnLhTexts` / `EnUsLhTexts` … |
| Injection | `Environment(\.lhColors)` | `Environment(\.lhTexts)` |
| Conteneur | `LhTheme(isDark:)` | `LhTheme` en interne (`LhLocale.shared`) |
| Surchamp partiel | `.lhColors(_)` | `.lhTexts(_)` |

Le paramètre `texts` de `LhTheme(isDark:colors:texts:)` offre une entrée de
surcharge explicite (packs de texte prédéfinis, extension réservée).

## Démo dans l'application de documentation

L'hôte de documentation natif (`LhDocsView`) propose, dans la section « 设置 » de
la barre latérale, le basculement du thème (suivre le système / clair / sombre)
et de la langue (10 intégrées plus une démo de pack personnalisé `vi`) afin de
vérifier directement le comportement multilingue.
