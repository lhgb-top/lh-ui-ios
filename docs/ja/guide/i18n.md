# 多言語対応

コンポーネントライブラリは 10 言語の内蔵テキストパックを同梱し、ホストによる
カスタム言語の登録もサポートします。仕組みは web 系血脈 `@lh-ui/share` の
`LhLocale` セマンティクスに沿っており、iOS の `LhColors` テーマ層と同構です。

## 言語範囲

| コード | 言語 | 備考 |
| --- | --- | --- |
| `zh-CN` | 简体中文 | 既定言語 |
| `zh-TW` | 繁體中文 | |
| `en-US` | English | |
| `ja-JP` | 日本語 | |
| `ko-KR` | 한국어 | |
| `de-DE` | Deutsch | ランタイム専用（ドキュメントサイトの 9 言語には独語を含めない） |
| `fr-FR` | Français | |
| `es` | Español | |
| `ar` | العربية | RTL。`LhTheme` が注入する `\.locale` によりレイアウト自動反転 |
| `ru` | Русский | |

> コードは web 系血脈 `lh-ui-share` の `LH_LANGUAGE_CONST` と文字単位で一致。
> zh-CN の確認/キャンセルは `specs/*.json` の `"确认"` / `"取消"` を採用（R-n5）。

## 適用範囲（重要）

`LhTexts` が扱うのは**ライブラリ自身**の内蔵文字列のみです：

- Dialog / Picker の確認/キャンセルボタンの既定文字（`confirmText` / `cancelText` が `nil` のとき）
- Loading / Switch のアクセシビリティラベル、placeholder 未設定時の
  Input / Textarea アクセシビリティフォールバック

呼び出し元が渡す文字列（`title` / `content` / `label` / `options` …）のローカライズは
**ホスト App の責任**です。これらはビジネス側で生成されるため、ライブラリは管理しません。

## 言語の切り替え

```swift
// グローバル切替：LhTheme が @ObservedObject でシングルトンを保持、
// 切替と同時にツリー全体を再描画
LhLocale.shared.setLocale("en-US")

// 現在の言語コード
LhLocale.shared.current  // "en-US"
```

`LhTheme` は現在のパックを `Environment(\.lhTexts)` に自動注入し、`\.locale` も
連動させます（ar は自動 RTL）。未登録の言語は**簡体字中国語パックの内容**に
フォールバックします（web 系血脈と同じ挙動）。

## カスタム言語

```swift
let vietnamese = LhTexts(
  dialogConfirm: "Xác nhận", dialogCancel: "Hủy",
  pickerConfirm: "Xác nhận", pickerCancel: "Hủy",
  loadingLabel: "Đang tải", switchLabel: "Công tắc",
  inputLabelFallback: "Trường văn bản",
  textareaLabelFallback: "Trường văn bản nhiều dòng"
)

LhLocale.shared.register("vi", pack: vietnamese)
LhLocale.shared.setLocale("vi")
```

`register` で登録したパックは**内蔵レジストリをシャドウ**します（内蔵パックが
上書きされることはありません）。登録した言語が現在の言語であれば即時反映されます。

## LhTexts

```swift
public struct LhTexts: Equatable, Sendable {
  public let dialogConfirm: String   // "确认" / "OK" / "確定" …
  public let dialogCancel: String
  public let pickerConfirm: String
  public let pickerCancel: String
  public let loadingLabel: String    // アクセシビリティラベル
  public let switchLabel: String
  public let inputLabelFallback: String
  public let textareaLabelFallback: String
}

public let ZhCnLhTexts = LhTexts(dialogConfirm: "确认", /* … */)
public let EnUsLhTexts = LhTexts(dialogConfirm: "Confirm", /* … */)
// … ZhTw / JaJp / KoKr / DeDe / FrFr / Es / Ar / Ru
```

イニシャライザは公開：単体テストで直接パックを構築してアサーションできます。
`LhTheme` で包まれていない場合、Environment キーの defaultValue は
`ZhCnLhTexts` にフォールバックします（缺省＝中国語、テーマ層の
「缺省＝明色」呼応）。

## テーマ層との関係

| | 色 | テキスト |
| --- | --- | --- |
| 値型 | `LhColors` | `LhTexts` |
| プリセット | `LightLhColors` / `DarkLhColors` | `ZhCnLhTexts` / `EnUsLhTexts` … |
| 注入 | `Environment(\.lhColors)` | `Environment(\.lhTexts)` |
| コンテナ | `LhTheme(isDark:)` | `LhTheme` 内部で自動（`LhLocale.shared`） |
| 段階的上書き | `.lhColors(_)` | `.lhTexts(_)` |

`LhTheme(isDark:colors:texts:)` の `texts` 引数が明示的な上書き入口です
（プリセットテキストパック、拡張として予約）。

## ドキュメント App のデモ

ネイティブドキュメントホスト（`LhDocsView`）のサイドバー「設定」セクションで、
テーマ（システムに従う / 明色 / 暗色）と言語（内蔵 10 言語 + `vi` カスタムパックの
デモ）を切り替えられ、多言語要件をそのまま検証できます。
