# Темы и тёмный режим

## Модель токенов

Единый источник токенов нативного направления — `lh-ui-core/tokens/*.json`, codegen генерирует артефакты для iOS:

| Артефакт | Содержимое | Тёмный режим |
| --- | --- | --- |
| `LhTokens` | Полная светлая тема: размеры Button, палитра Color, Motion, Radius, Shadow, Spacing, Typography, ZIndex | — |
| `LhDarkTokens` | Только подобъект `Color` (модель **параллельных объектов**) | Тёмный режим переопределяет только цвета; размеры, анимация и скругления в тёмном режиме не меняются |
| `LhShadow` | Структура-носитель тени SwiftUI (color/opacity/radius/x/y) | — |

> Это согласуется с android / harmony / windows (параллельные объекты) и отличается от стороны docs (поверхностное слияние JSON).
> Тематический слой спроектирован исходя из этого: `LhColors` хранит только цвета, а размеры компоненты берут напрямую из `LhTokens`.

## LhColors

`LightLhColors` / `DarkLhColors` разворачивают два сгенерированных enum в один тип-значение `Equatable`:

```swift
public struct LhColors: Equatable {
  public let primary: Color
  public let onPrimary: Color
  // ... все семантические цвета
}

public let LightLhColors = LhColors(primary: LhTokens.Color.Primary.`default`, /* ... */)
public let DarkLhColors = LhColors(primary: LhDarkTokens.Color.Primary.`default`, /* ... */)
```

Инициализатор публичный: модульные тесты могут собирать палитру напрямую для утверждений; прикладной код должен потреблять её через `LhTheme`.

## LhTheme

```swift
LhTheme(isDark: true) {
  // Environment(\.lhColors) внедряет DarkLhColors, компоненты внутри потребляют его автоматически
}
```

Без обёртки `LhTheme` defaultValue ключа Environment откатывается к `LightLhColors` (по умолчанию светлая тема).

## Предвычисление тёмного режима (важно)

В направлении web тёмный режим вычисляется динамически через CSS `color-mix()`, но в нативе нет CSS-каскада, поэтому core **предвычисляет тёмные выражения до литералов** (например `rgba(61,100,158,0.25)`, `#B1C1D8`). Следствие (генеральный план R-n6):

> **При изменении основного цвета пресета предвычисленные тёмные значения не обновляются автоматически** — их нужно пересчитать вручную и обновить `lh-ui-core/tokens/color-dark.json`, а также обновить *Базовый стандарт языка дизайна*.

## Специфика iOS-стороны

- **Длительности в секундах**: `LhTokens.Motion.Duration.base = 0.300` (на android/harmony и в C — миллисекунды); API анимаций SwiftUI потребляет значение напрямую, пересчёт не нужен.
- **Представление цветов**: сгенерированные артефакты используют нормализованный RGB (`SwiftUI.Color(red:green:blue:)` + `.opacity()`), без hex-строк.
- **Скругления**: `Radius.circle` — это доля 0.5, на стороне платформы пересчитывается как `min(ширина, высота)/2`, использовать её как pt нельзя.
- **Тени**: SwiftUI не поддерживает расширение (spread), поэтому сгенерированный `LhShadow` игнорирует spread (с пометкой в комментарии).
- **Шрифты**: `Typography.fontFamily` — строка со стеком шрифтов, на стороне платформы берётся первое доступное семейство; китайский серифный шрифт — это характер по умолчанию.
