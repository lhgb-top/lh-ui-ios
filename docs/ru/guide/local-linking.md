# Локальная линковка

## Соглашение о структуре семейства

```
lh-ui/                        # родительский каталог семейства (не репозиторий)
├── lh-ui-core/               # источник токенов + codegen
├── lh-ui-android/            # репозитории-братья
├── lh-ui-ios/                # этот репозиторий
├── lh-ui-harmony/
└── lh-ui-windows/
```

Когда все репозитории находятся в одном родительском каталоге, токены **линкуются локально**; если репозиториев-братьев нет (одиночный clone в CI), выполняется **автоматический откат на npm-пакет**.
Это структурно аналогично механизму защиты vite alias в направлении web (генеральный план D18).

## Трёхуровневая защита

`scripts/link-tokens.mjs` ищет артефакты токенов в порядке приоритета:

| Приоритет | Источник | Описание |
| --- | --- | --- |
| 1 | `../lh-ui-core/dist/ios` | Локальная линковка: изменение токенов применяется мгновенно |
| 2 | `node_modules/@lh-ui/core/dist/ios` | Откат на npm: `files:["dist"]` у `@lh-ui/core` содержит артефакты для четырёх платформ |
| 3 | — | Выход с ошибкой: без токенов сборка невозможна |

## Повседневный процесс

```bash
# 1. Изменить токены (в репозитории core)
cd ../lh-ui-core
vim tokens/color.json           # или spacing / typography / ...

# 2. Перегенерировать и проверить
pnpm codegen                    # генерирует артефакты в dist/ для четырёх платформ
pnpm verify                     # schema + ссылки + контрастность WCAG + согласованность контрактов

# 3. Синхронизировать в этом репозитории
cd ../lh-ui-ios
pnpm link:tokens                # перезаписывает Sources/LhUITokens/

# 4. Регрессия
swift test
```

## Защита в CI

```bash
pnpm link:tokens:check          # проверяет, синхронизированы ли токены (сравнение количества файлов, при расхождении код выхода 1)
```

## Запрещено

- ❌ Ручное редактирование `Sources/LhUITokens/` (генерируемый артефакт, в gitignore)
- ❌ Коммит сгенерированных файлов токенов в репозиторий
- ❌ Писать литералы цветов/отступов в компонентах (например `Color(red: 0.169, ...)`, `CGFloat(40)`, шрифт `14`)
- ❌ Копировать артефакты вручную в обход `link:tokens`

## Диагностика

| Симптом | Причина | Решение |
| --- | --- | --- |
| При компиляции `cannot find 'LhTokens' in scope` | Токены не синхронизированы | `pnpm link:tokens` |
| Значения токенов не соответствуют ожиданиям | В репозитории core не выполнен повторный codegen | Выполнить `pnpm codegen` в core и повторить link |
| `link:tokens` сообщает «артефакты токенов не найдены» | Репозиториев-братьев нет, а npm-пакет не установлен | Проверить структуру семейства или `pnpm i -D @lh-ui/core` |
| Тёмные цвета неверны | Изменили светлый основной цвет, но не обновили предвычисленные тёмные значения | Обновить `color-dark.json` и перезапустить (R-n6) |
| Ошибки компиляции, связанные с `default` | Имя члена сгенерированного артефакта не экранировано как ключевое слово | Обновить core (исправлено: имена членов заключаются в обратные кавычки `` `default` ``) |
