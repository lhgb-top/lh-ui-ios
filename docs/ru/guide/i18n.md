# Локализация

Библиотека компонентов поставляется со встроенными текстовыми пакетами для 10
языков и позволяет хост-приложению регистрировать собственные языки. Механизм
следует семантике `LhLocale` веб-линии (`@lh-ui/share`) и структурно
идентичен слою темы `LhColors` в iOS.

## Охват языков

| Код | Язык | Примечания |
| --- | --- | --- |
| `zh-CN` | 简体中文 | Язык по умолчанию |
| `zh-TW` | 繁體中文 | |
| `en-US` | English | |
| `ja-JP` | 日本語 | |
| `ko-KR` | 한국어 | |
| `de-DE` | Deutsch | Только рантайм (9 языков сайта документации не включают немецкий) |
| `fr-FR` | Français | |
| `es` | Español | |
| `ar` | العربية | RTL; `LhTheme` внедряет `\.locale`, и раскладка инвертируется автоматически |
| `ru` | Русский | |

> Коды посимвольно совпадают с `LH_LANGUAGE_CONST` веб-линии `lh-ui-share`;
> значения confirm/cancel для zh-CN взяты из `specs/*.json`
> (`"确认"` / `"取消"`, R-n5).

## Область действия (важно)

`LhTexts` хранит только **внутренние** строки самой библиотеки:

- Текст по умолчанию кнопок подтверждения/отмены в Dialog / Picker (когда `confirmText` / `cancelText` равен `nil`)
- Метки доступности Loading / Switch, а также метки-заглушки доступности
  Input / Textarea, если placeholder не задан

Локализация текста, передаваемого вызывающей стороной (`title` / `content` /
`label` / `options` …), — **зона ответственности хост-приложения**: эти строки
порождаются бизнес-логикой, библиотека их не контролирует.

## Переключение языка

```swift
// Глобальное переключение: LhTheme удерживает singleton через @ObservedObject,
// поэтому переключение перерисовывает всё дерево
LhLocale.shared.setLocale("en-US")

// Текущий код языка
LhLocale.shared.current  // "en-US"
```

`LhTheme` автоматически внедряет текущий пакет в `Environment(\.lhTexts)` и
синхронизирует `\.locale` (ar автоматически RTL). Незарегистрированные языки делают fallback на **содержимое пакета упрощённого китайского** (как в веб-линии).

## Пользовательские языки

```swift
let vietnamese = LhTexts(
  dialogConfirm: "Xác nhận", dialogCancel: "Hủy",
  pickerConfirm: "Xác nhận", pickerCancel: "Hủy",
  loadingLabel: "Đang tải", switchLabel: "Công tắc",
  inputLabelFallback: "Trường văn bản",
  textareaLabelFallback: "Trường văn bản nhiều dòng"
)

LhLocale.shared.register("vi", pack: vietnamese)
LhLocale.shared.setLocale("vi")
```

Пакеты, зарегистрированные через `register`, **перекрывают встроенный реестр**
(встроенные пакеты никогда не перезаписываются); если зарегистрированный язык
является текущим, применение происходит немедленно.

## LhTexts

```swift
public struct LhTexts: Equatable, Sendable {
  public let dialogConfirm: String   // "确认" / "OK" / "確定" …
  public let dialogCancel: String
  public let pickerConfirm: String
  public let pickerCancel: String
  public let loadingLabel: String    // метка доступности
  public let switchLabel: String
  public let inputLabelFallback: String
  public let textareaLabelFallback: String
}

public let ZhCnLhTexts = LhTexts(dialogConfirm: "确认", /* … */)
public let EnUsLhTexts = LhTexts(dialogConfirm: "Confirm", /* … */)
// … ZhTw / JaJp / KoKr / DeDe / FrFr / Es / Ar / Ru
```

Инициализатор публичный: модульные тесты могут собирать пакеты напрямую. Без
обёртки `LhTheme` defaultValue ключа Environment fallback'ает на
`ZhCnLhTexts` (китайский по умолчанию — зеркально «светлая тема по умолчанию»
слоя темы).

## Связь со слоем темы

| | Цвета | Тексты |
| --- | --- | --- |
| Тип-значение | `LhColors` | `LhTexts` |
| Пресеты | `LightLhColors` / `DarkLhColors` | `ZhCnLhTexts` / `EnUsLhTexts` … |
| Внедрение | `Environment(\.lhColors)` | `Environment(\.lhTexts)` |
| Контейнер | `LhTheme(isDark:)` | `LhTheme` внутренне (`LhLocale.shared`) |
| Точечное переопределение | `.lhColors(_)` | `.lhTexts(_)` |

Параметр `texts` в `LhTheme(isDark:colors:texts:)` даёт явную точку
переопределения (пресеты текстовых пакетов, зарезервированное расширение).

## Демо в приложении документации

Нативный хост документации (`LhDocsView`) в секции «设置» боковой панели
предлагает переключение темы (по системе / светлая / тёмная) и языка
(10 встроенных + демо пользовательского пакета `vi`), чтобы напрямую проверить
многоязычное поведение.
