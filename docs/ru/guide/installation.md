# Установка

## Требования к окружению

- Xcode 15+, Swift 5.9+
- iOS 15.0+ (macOS 12+ нужна только для запуска XCTest на хосте)
- Сборочный инструментарий: Node.js >= 20 + pnpm (используется только для линковки токенов и сайта документации, **в рантайм не попадает**)

## Подключение через SPM

В Xcode: File → Add Package Dependencies…, укажите адрес этого репозитория; либо отредактируйте `Package.swift` напрямую:

```swift
dependencies: [
  .package(url: "https://github.com/lhgb-top/lh-ui-ios", from: "0.0.1")
],
targets: [
  .target(name: "MyApp", dependencies: [.product(name: "LhUI", from: "lh-ui-ios")])
]
```

Таргет токенов `LhUITokens` подключается автоматически вместе с зависимостью `LhUI` (таргет внутри SPM-пакета, отдельно объявлять его не нужно).

## Синхронизация токенов (при разработке этого репозитория из исходников)

Токены — генерируемый артефакт, их нужно синхронизировать из `lh-ui-core` (единственный источник, ручное редактирование запрещено):

```bash
cd ../lh-ui-core && pnpm codegen   # генерирует артефакты токенов в dist/ios
cd ../lh-ui-ios
pnpm install                        # устанавливает сборочный инструментарий
pnpm link:tokens                    # синхронизирует токены в Sources/LhUITokens/
```

В `pnpm link:tokens` действует трёхуровневая проверка наличия: локальный `../lh-ui-core/dist/ios` → npm-артефакт `@lh-ui/core` → ошибка.

## Проверка установки

```bash
swift build        # компиляция
swift test         # золотые сценарии (достаточно хоста macOS, эмулятор не нужен)
```
