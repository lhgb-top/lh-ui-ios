# الربط المحلي

## اصطلاح تخطيط العائلة

```
lh-ui/                        # الدليل الأب للعائلة (ليس مستودعًا)
├── lh-ui-core/               # المصدر الأصلي للرموز + codegen
├── lh-ui-android/            # مستودع شقيق
├── lh-ui-ios/                # هذا المستودع
├── lh-ui-harmony/
└── lh-ui-windows/
```

عند وجود جميع المستودعات تحت الدليل الأب نفسه، تُربط الرموز **محليًا مباشرةً**؛ وعند غياب المستودعات الشقيقة (استنساخ مستودع واحد في CI) **يُرجَع تلقائيًا إلى حزمة npm**.
وهي آلية متماثلة مع حارس vite alias في سلالة الويب (الخطة الرئيسية D18).

## حارس من ثلاث مستويات

يبحث `scripts/link-tokens.mjs` عن منتجات الرموز وفق ترتيب الأولوية:

| الأولوية | المصدر | الوصف |
| --- | --- | --- |
| 1 | `../lh-ui-core/dist/ios` | ربط محلي: تعديل الرمز يسري فورًا |
| 2 | `node_modules/@lh-ui/core/dist/ios` | الرجوع إلى npm: حقل `files:["dist"]` في `@lh-ui/core` يحتوي على منتجات المنصات الأربع |
| 3 | — | خطأ والخروج: دون رموز لا يمكن البناء |

## الروتين اليومي

```bash
# 1. تعديل الرموز (في مستودع core)
cd ../lh-ui-core
vim tokens/color.json           # أو spacing / typography / ...

# 2. إعادة التوليد + التحقق
pnpm codegen                    # يولّد منتجات dist/ للمنصات الأربع
pnpm verify                     # schema + المراجع + تباين WCAG + تناسق العقود

# 3. العودة إلى هذا المستودع للمزامنة
cd ../lh-ui-ios
pnpm link:tokens                # يستبدل Sources/LhUITokens/

# 4. الانحدار
swift test
```

## بوابة CI

```bash
pnpm link:tokens:check          # يتحقق مما إذا كانت الرموز قد تمت مزامنتها (مقارنة عدد الملفات، رمز الخروج 1 إن لم تكن)
```

## ممنوعات

- ❌ التعديل اليدوي على `Sources/LhUITokens/` (نتاج توليد، ومُجاهَل في git)
- ❌ إيداع ملفات الرموز المولّدة في المستودع
- ❌ كتابة قيم حرفية للألوان والمسافات داخل المكوّنات (مثل `Color(red: 0.169, ...)` و`CGFloat(40)` وخط بحجم `14`)
- ❌ تجاوز `link:tokens` ونسخ المنتجات يدويًا

## استكشاف الأخطاء

| العَرَض | السبب | الحل |
| --- | --- | --- |
| خطأ في الترجمة `cannot find 'LhTokens' in scope` | الرموز غير مُزامَنة | `pnpm link:tokens` |
| قيمة الرمز لا تطابق المتوقع | لم يُعِد مستودع core تشغيل codegen | تشغيل `pnpm codegen` في core ثم إعادة الربط |
| `link:tokens` يُبلغ عن «لم يُعثر على منتج الرموز» | المستودعات الشقيقة غير موجودة ولم تُثبَّت حزمة npm | التحقق من تخطيط العائلة أو `pnpm i -D @lh-ui/core` |
| ألوان داكنة غير صحيحة | عُدّل اللون الرئيسي الفاتح دون تحديث الحساب المسبق للداكن | تحديث `color-dark.json` وإعادة التشغيل (R-n6) |
| أخطاء ترجمة تتعلق بـ `default` | اسم العضو في المنتج المولّد لم يُهرَّب (كلمة محجوزة) | ترقية core (تم الإصلاح: أسماء الأعضاء تحمل شرطة خلفية `` `default` ``) |
