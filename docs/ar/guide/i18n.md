# التدويل

تأتي مكتبة المكوّنات بحزم نصوص مدمجة لعشر لغات، وتتيح للمضيف تسجيل لغات مخصصة.
يتوافق التصميم مع دلالات `LhLocale` من سلالة الويب (`@lh-ui/share`) ويتطابق
بنيوياً مع طبقة السمات `LhColors` في iOS.

## تغطية اللغات

| الرمز | اللغة | ملاحظات |
| --- | --- | --- |
| `zh-CN` | 简体中文 | اللغة الافتراضية |
| `zh-TW` | 繁體中文 | |
| `en-US` | English | |
| `ja-JP` | 日本語 | |
| `ko-KR` | 한국어 | |
| `de-DE` | Deutsch | وقت التشغيل فقط (لغات موقع التوثيق التسع تستثني الألمانية) |
| `fr-FR` | Français | |
| `es` | Español | |
| `ar` | العربية | RTL؛ يُقلب التخطيط تلقائياً عبر `\.locale` الذي يُحقنه `LhTheme` |
| `ru` | Русский | |

> تتطابق الرموز حرفياً مع `LH_LANGUAGE_CONST` في سلالة الويب `lh-ui-share`،
> وقيمتا التأكيد/الإلغاء في `zh-CN` تأتيان من `specs/*.json`
> (`"确认"` / `"取消"`، R-n5).

## النطاق (مهم)

يحمل `LhTexts` فقط السلاسل **الخاصة بالمكتبة نفسها**:

- النص الافتراضي لزري التأكيد/الإلغاء في Dialog / Picker (عندما يكون `confirmText` / `cancelText` بقيمة `nil`)
- وسوم إتاحة Loading / Switch، ووسيم إتاحة Input / Textarea
  عند عدم تعيين placeholder

ترجمة النصوص التي يمررها المستدعي (`title` / `content` / `label` /
`options` …) هي **مسؤولية تطبيق المضيف** — فهذه السلاسل تأتي من منطق العمل
ولا تديرها المكتبة.

## تبديل اللغة

```swift
// تبديل شامل: يحتفظ LhTheme بالنسخة الفردية عبر @ObservedObject،
// فيُعاد رسم الشجرة بأكملها فور التبديل
LhLocale.shared.setLocale("en-US")

// رمز اللغة الحالي
LhLocale.shared.current  // "en-US"
```

يُحقن `LhTheme` الحزمة الحالية تلقائياً في `Environment(\.lhTexts)` ويُشغّل
`\.locale` (تتجه ar إلى RTL تلقائياً). اللغات غير المُسجَّلة ترجع إلى
**محتوى حزمة الصينية المبسطة** (مثل سلالة الويب).

## لغات مخصصة

```swift
let vietnamese = LhTexts(
  dialogConfirm: "Xác nhận", dialogCancel: "Hủy",
  pickerConfirm: "Xác nhận", pickerCancel: "Hủy",
  loadingLabel: "Đang tải", switchLabel: "Công tắc",
  inputLabelFallback: "Trường văn bản",
  textareaLabelFallback: "Trường văn bản nhiều dòng"
)

LhLocale.shared.register("vi", pack: vietnamese)
LhLocale.shared.setLocale("vi")
```

تحجوم الحزم المُسجَّلة عبر `register` **السجل المدمج** (لا تُستبدل الحزم
المدمجة أبداً)؛ وإذا كانت اللغة المُسجَّلة هي اللغة الحالية تُطبَّق فوراً.

## LhTexts

```swift
public struct LhTexts: Equatable, Sendable {
  public let dialogConfirm: String   // "确认" / "OK" / "確定" …
  public let dialogCancel: String
  public let pickerConfirm: String
  public let pickerCancel: String
  public let loadingLabel: String    // وسم الإتاحة
  public let switchLabel: String
  public let inputLabelFallback: String
  public let textareaLabelFallback: String
}

public let ZhCnLhTexts = LhTexts(dialogConfirm: "确认", /* … */)
public let EnUsLhTexts = LhTexts(dialogConfirm: "Confirm", /* … */)
// … ZhTw / JaJp / KoKr / DeDe / FrFr / Es / Ar / Ru
```

المُهيِّئ عام: يمكن لاختبارات الوحدة بناء الحزم مباشرة. دون غلاف `LhTheme`
ترجع القيمة الافتراضية لمفتاح Environment إلى `ZhCnLhTexts`
(الصينية افتراضياً، يوازي «الوضع الفاتح افتراضياً» في طبقة السمات).

## العلاقة بطبقة السمات

| | الألوان | النصوص |
| --- | --- | --- |
| نوع القيمة | `LhColors` | `LhTexts` |
| الإعدادات المسبقة | `LightLhColors` / `DarkLhColors` | `ZhCnLhTexts` / `EnUsLhTexts` … |
| الحقن | `Environment(\.lhColors)` | `Environment(\.lhTexts)` |
| الحاوية | `LhTheme(isDark:)` | `LhTheme` داخلياً (`LhLocale.shared`) |
| تجاوز جزئي | `.lhColors(_)` | `.lhTexts(_)` |

يوفّر معامل `texts` في `LhTheme(isDark:colors:texts:)` مدخلاً صريحاً للتجاوز
(حزم نصوص مسبقة، امتداد محجوز).

## عرض في تطبيق التوثيق

يوفّر مضيف التوثيق الأصلي (`LhDocsView`) في قسم «设置» بالشريط الجانبي تبديل
السمة (حسب النظام / فاتح / داكن) واللغة (10 مدمجة + عرض `vi` لحزمة مخصصة)
للتحقق من السلوك متعدد اللغات مباشرة.
