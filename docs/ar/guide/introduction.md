# مقدمة

**lh-ui-ios** هو تطبيق iOS التابع لـ **سلالة أصلية** من عائلة lh-ui: مكتبة مكوّنات واجهة مستخدم مبنية على **Swift + SwiftUI**.

## موقعها في العائلة

```
                        ┌── سلالة الويب: share (core بلغة TS + SCSS) → plus / vue2 / react / uniapp
عائلة lh-ui (العلامة نفسها) ─────┤
                        └── سلالة أصلية: core (رموز JSON + عقود + codegen) → android / ios / harmony / windows
                                                                    ↑ هذا المستودع
```

- **مركز وقت البناء**: `lh-ui-core` هو المصدر الأصلي للرموز في السلالة الأصلية (`tokens/*.json`)، وعقود المكوّنات (`specs/`)، والحالات الذهبية (`cases/`)، وأدوات codegen. يولّد هياكل رموز Swift (`LhTokens` / `LhDarkTokens` / `LhShadow`)، **دون توليد أي تطبيق واجهة**.
- **مسؤوليات هذا المستودع**: كتابة SwiftUI View يدويًا، ودمج السمات (الحقن عبر Environment)، وتعدادات الخصائص وربط القيم الافتراضية، وترجمة الحالات الذهبية إلى XCTest.
- **مستقلة عن سلالة الويب**: لا تبعية على `@lh-ui/share`، ولا قيد متبادل بين الإصدارات. يتم محاذاة التناسق البصري يدويًا عبر *خط أساس لغة التصميم*.

## لغة التصميم

سمة النمط الصيني: لون رئيسي أزرق 青花瓷 (الخزف الأزرق) (`#2B4C7C`)، خلفية بيضاء 宣纸白 (أبيض ورق الأرز) (`#FAF6F0`)، نجاح بلون 松花绿 (أخضر الصنوبر)، تحذير بلون 藤黄 (أصفر عشبي)، خطر بلون 朱砂 (زنجفر)، ورصة خطوط serif (Noto Serif SC → STSong → SimSun). كل القيم البصرية هي رموز، ولا تظهر أي قيمة حرفية في المكوّنات.

## لماذا SwiftUI

- واجهة تعريفية من الدرجة الأولى في المنصة، متماثلة ذهنيًا مع Compose / ArkUI، مما يسهّل محاذاة العقود عبر المنصات
- دمج بنقرة واحدة عبر SPM، دون وقت تشغيل JS ودون طبقة وسيطة
- `#Preview` هو التوثيق، و `View` هو المكوّن: تماثل مع تجربة تطوير SFC في سلالة الويب

## الحالة الحالية

- **اكتمل نموذج button الشامل وتم تسليمه** (استهلاك الرموز + تحليل المظهر عبر resolveAppearance + SwiftUI View + XCTest + `#Preview` + موقع التوثيق)
- ستُكمل لاحقًا بقية مكوّنات P0 الـ 13 (icon / input / textarea / cell / checkbox / radio / switch / tag / dialog / toast / loading / picker / navbar) وفق النمط ذاته
