  - title: 토큰 주도
    details: 컴포넌트에 하드코딩된 색상이나 간격이 없고, core codegen이 생성한 LhTokens / LhDarkTokens를 소비합니다. 토큰을 바꾸면 모든 단에 즉시 반영됩니다.
  - title: 계약 일치
    details: props 이름이 lh-ui-core/specs와 글자 단위로 정렬되어, Android / harmony / Windows 및 web 혈통과 행동을 공유합니다.
  - title: 골든 케이스 수호
    details: cases/button.json의 행동 단언이 XCTest로 번역되어, macOS 호스트에서 바로 실행할 수 있습니다(시뮬레이터 불필요).
  - title: 라이트/다크 듀얼 테마
    details: LhTheme 한 줄로 전환합니다. 다크 토큰은 core에서 미리 계산되어 런타임 조색이 없고 깜빡임도 없습니다.
  - title: 중국풍 디자인 언어
    details: 青花瓷(청화자) 블루 주색, 宣纸(선지) 화이트 배경, 藤黄(등황) · 朱砂(진사) 포인트, 세리프 폰트 스택으로 web 혈통과 같은 원본, 같은 값을 사용합니다.
  - title: SwiftUI 네이티브
    details: 순수 Swift + SwiftUI로 손으로 작성한 UI, JS 런타임 없는 선언형 UI 일등 시민, SPM으로 한 번에 연결합니다.
