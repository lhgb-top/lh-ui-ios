# 다국어

컴포넌트 라이브러리는 10종 언어의 내장 텍스트 팩을 제공하며, 호스트가 커스텀 언어를
등록할 수도 있습니다. 메커니즘은 web 혈통 `@lh-ui/share`의 `LhLocale` 의미론을
따르며, iOS의 `LhColors` 테마 층과 동일한 구조입니다.

## 언어 범위

| 코드 | 언어 | 비고 |
| --- | --- | --- |
| `zh-CN` | 简体中文 | 기본 언어 |
| `zh-TW` | 繁體中文 | |
| `en-US` | English | |
| `ja-JP` | 日本語 | |
| `ko-KR` | 한국어 | |
| `de-DE` | Deutsch | 런타임 전용 (문서 사이트 9개 언어에는 독일어 제외) |
| `fr-FR` | Français | |
| `es` | Español | |
| `ar` | العربية | RTL. `LhTheme`이 주입하는 `\.locale`로 레이아웃이 자동 반전 |
| `ru` | Русский | |

> 코드는 web 혈통 `lh-ui-share`의 `LH_LANGUAGE_CONST`와 글자 단위로 일치합니다.
> zh-CN의 확인/취소 값은 `specs/*.json`의 `"确认"` / `"取消"`를 따릅니다 (R-n5).

## 적용 범위 (중요)

`LhTexts`는 **라이브러리 자체**의 내장 문자열만 담당합니다:

- Dialog / Picker의 확인/취소 버튼 기본 글자 (`confirmText` / `cancelText`가 `nil`일 때)
- Loading / Switch의 접근성 라벨, placeholder 미설정 시
  Input / Textarea 접근성 폴백

호출 측이 전달하는 문자열 (`title` / `content` / `label` / `options` …)의 현지화는
**호스트 App의 책임**입니다. 이 문자열은 비즈니스에서 생성되며 라이브러리가
관리하지 않습니다.

## 언어 전환

```swift
// 전역 전환: LhTheme이 @ObservedObject로 싱글톤을 보유하여
// 전환 즉시 트리 전체를 다시 렌더링
LhLocale.shared.setLocale("en-US")

// 현재 언어 코드
LhLocale.shared.current  // "en-US"
```

`LhTheme`은 현재 팩을 `Environment(\.lhTexts)`에 자동 주입하고 `\.locale`에
연동합니다 (ar은 자동 RTL). 등록되지 않은 언어는 **간체 중국어 팩 내용**으로
폴백합니다 (web 혈통과 동일).

## 커스텀 언어

```swift
let vietnamese = LhTexts(
  dialogConfirm: "Xác nhận", dialogCancel: "Hủy",
  pickerConfirm: "Xác nhận", pickerCancel: "Hủy",
  loadingLabel: "Đang tải", switchLabel: "Công tắc",
  inputLabelFallback: "Trường văn bản",
  textareaLabelFallback: "Trường văn bản nhiều dòng"
)

LhLocale.shared.register("vi", pack: vietnamese)
LhLocale.shared.setLocale("vi")
```

`register`로 등록한 팩은 **내장 레지스트리를 가립니다** (내장 팩은 덮어써지지
않습니다). 등록한 언어가 현재 언어이면 즉시 적용됩니다.

## LhTexts

```swift
public struct LhTexts: Equatable, Sendable {
  public let dialogConfirm: String   // "确认" / "OK" / "確定" …
  public let dialogCancel: String
  public let pickerConfirm: String
  public let pickerCancel: String
  public let loadingLabel: String    // 접근성 라벨
  public let switchLabel: String
  public let inputLabelFallback: String
  public let textareaLabelFallback: String
}

public let ZhCnLhTexts = LhTexts(dialogConfirm: "确认", /* … */)
public let EnUsLhTexts = LhTexts(dialogConfirm: "Confirm", /* … */)
// … ZhTw / JaJp / KoKr / DeDe / FrFr / Es / Ar / Ru
```

초기화는 공개: 단위 테스트에서 직접 팩을 구성해 단언할 수 있습니다.
`LhTheme`으로 감싸지 않은 경우 Environment 키의 defaultValue는
`ZhCnLhTexts`로 폴백합니다 (기본값=중국어, 테마 층의
"기본값=밝은 색"에 대응).

## 테마 층과의 관계

| | 색상 | 텍스트 |
| --- | --- | --- |
| 값 타입 | `LhColors` | `LhTexts` |
| 프리셋 | `LightLhColors` / `DarkLhColors` | `ZhCnLhTexts` / `EnUsLhTexts` … |
| 주입 | `Environment(\.lhColors)` | `Environment(\.lhTexts)` |
| 컨테이너 | `LhTheme(isDark:)` | `LhTheme` 내부 자동 (`LhLocale.shared`) |
| 단계적 덮어쓰기 | `.lhColors(_)` | `.lhTexts(_)` |

`LhTheme(isDark:colors:texts:)`의 `texts` 매개변수가 명시적 덮어쓰기
입구입니다 (프리셋 텍스트 팩, 확장 용도로 예약).

## 문서 App 데모

네이티브 문서 호스트 (`LhDocsView`) 사이드바의 "设置" (설정) 섹션에서
테마 (시스템 따르기 / 밝게 / 어둡게)와 언어 (내장 10종 + `vi` 커스텀 팩 데모)를
전환하여 다국어 동작을 직접 검증할 수 있습니다.
