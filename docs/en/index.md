features:
  - title: Token-driven
    details: Components contain zero hardcoded colors or spacing — they all consume the LhTokens / LhDarkTokens generated by core codegen, so changing a token takes effect across the whole app instantly.
  - title: Spec-aligned
    details: Prop names line up verbatim with lh-ui-core/specs, sharing behavior with the Android / HarmonyOS / Windows ends and the web bloodline.
  - title: Golden-case guarded
    details: The behavioral assertions from cases/button.json are translated into XCTest, runnable on the macOS host (no simulator required).
  - title: Light & dark themes
    details: LhTheme toggles in one line; dark tokens are pre-computed by core — no runtime color mixing, no flicker.
  - title: Chinese-style design language
    details: 青花瓷 (ceramic blue) primary, 宣纸白 (rice-paper white) background, 藤黄 (gamboge) and 朱砂 (cinnabar) accents, a serif font stack — same source, same values as the web bloodline.
  - title: Native SwiftUI
    details: Hand-written pure Swift + SwiftUI UI, no JS runtime, first-class declarative UI, added via SPM in one step.
