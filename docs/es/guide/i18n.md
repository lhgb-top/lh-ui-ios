# Internacionalización

La biblioteca de componentes incluye paquetes de texto integrados para 10 idiomas
y permite a la aplicación host registrar idiomas personalizados. El mecanismo
refleja la semántica de `LhLocale` de la sangre web (`@lh-ui/share`) y es
estructuralmente idéntico a la capa de temas `LhColors` de iOS.

> `lh-ui-share`; los valores zh-CN de confirmar/cancelar provienen de
> `specs/*.json` (`"确认"` / `"取消"`, R-n5).

## Ámbito (importante)

`LhTexts` solo transporta las cadenas integradas **de la propia biblioteca**:

- El texto por defecto de los botones confirmar/cancelar de Dialog / Picker (cuando `confirmText` / `cancelText` es `nil`)
- Las etiquetas de accesibilidad de Loading / Switch, y el repuesto de accesibilidad
  de Input / Textarea cuando no hay placeholder

La localización del texto suministrado por quien llama (`title` / `content` /
`label` / `options` …) es **responsabilidad de la aplicación host**: esas cadenas
provienen del negocio y la biblioteca no las gestiona.

## Cambiar de idioma

```swift
// Cambio global: LhTheme mantiene el singleton con @ObservedObject,
// así que el cambio re-renderiza todo el árbol
LhLocale.shared.setLocale("en-US")

// Código de idioma actual
LhLocale.shared.current  // "en-US"
```

`LhTheme` inyecta automáticamente el paquete actual en `Environment(\.lhTexts)`
y sincroniza `\.locale` (ar pasa a RTL solo). Los idiomas no registrados caen
al **contenido del paquete de chino simplificado** (igual que la sangre web).

## Idiomas personalizados

```swift
let vietnamese = LhTexts(
  dialogConfirm: "Xác nhận", dialogCancel: "Hủy",
  pickerConfirm: "Xác nhận", pickerCancel: "Hủy",
  loadingLabel: "Đang tải", switchLabel: "Công tắc",
  inputLabelFallback: "Trường văn bản",
  textareaLabelFallback: "Trường văn bản nhiều dòng"
)

LhLocale.shared.register("vi", pack: vietnamese)
LhLocale.shared.setLocale("vi")
```

Los paquetes registrados con `register` **cubren el registro integrado** (los
paquetes integrados nunca se sobrescriben); si el idioma registrado es el actual,
se aplica de inmediato.

## LhTexts

```swift
public struct LhTexts: Equatable, Sendable {
  public let dialogConfirm: String   // "确认" / "OK" / "確定" …
  public let dialogCancel: String
  public let pickerConfirm: String
  public let pickerCancel: String
  public let loadingLabel: String    // etiqueta de accesibilidad
  public let switchLabel: String
  public let inputLabelFallback: String
  public let textareaLabelFallback: String
}

public let ZhCnLhTexts = LhTexts(dialogConfirm: "确认", /* … */)
public let EnUsLhTexts = LhTexts(dialogConfirm: "Confirm", /* … */)
// … ZhTw / JaJp / KoKr / DeDe / FrFr / Es / Ar / Ru
```

El inicializador es público: las pruebas unitarias pueden construir paquetes
directamente. Sin un envoltorio `LhTheme`, el defaultValue de la clave Environment
cae a `ZhCnLhTexts` (chino por defecto, espejo del "modo claro por defecto" de la
capa de temas).

## Relación con la capa de temas

| | Colores | Textos |
| --- | --- | --- |
| Tipo de valor | `LhColors` | `LhTexts` |
| Predefinidos | `LightLhColors` / `DarkLhColors` | `ZhCnLhTexts` / `EnUsLhTexts` … |
| Inyección | `Environment(\.lhColors)` | `Environment(\.lhTexts)` |
| Contenedor | `LhTheme(isDark:)` | `LhTheme` internamente (`LhLocale.shared`) |
| Anulación parcial | `.lhColors(_)` | `.lhTexts(_)` |

El parámetro `texts` de `LhTheme(isDark:colors:texts:)` ofrece una entrada de
anulación explícita (paquetes de texto predefinidos, extensión reservada).

## Demo en la app de documentación

El host de documentación nativo (`LhDocsView`) ofrece en la sección «设置» de la
barra lateral el cambio de tema (según el sistema / claro / oscuro) y de idioma
(10 integrados más una demo de paquete personalizado `vi`) para verificar el
comportamiento multilingüe directamente.
