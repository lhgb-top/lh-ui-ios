features:
  - title: Impulsada por tokens
    details: "Ningún valor de color o espaciado codificado de forma fija en los componentes: todos consumen los LhTokens / LhDarkTokens generados por el codegen de core. Al cambiar un token, el efecto se aplica al instante en toda la plataforma."
  - title: Contratos coherentes
    details: El nombrado de las props está alineado palabra por palabra con lh-ui-core/specs, compartiendo comportamiento con Android / HarmonyOS / Windows y el linaje web.
  - title: Resguardo de casos dorados
    details: Las aserciones de comportamiento de cases/button.json se traducen a XCTest, ejecutables en el host macOS (sin simulador).
  - title: Temas claro y oscuro
    details: "LhTheme se alterna en una línea; los tokens oscuros están precalculados por core: sin mezcla de colores en tiempo de ejecución, sin parpadeo."
  - title: Lenguaje de diseño estilo chino
    details: Color principal azul 青花瓷 (porcelana azul y blanco), fondo blanco 宣纸 (papel de arroz), toques 藤黄 (amarillo herbáceo) y 朱砂 (cinabre), pila de fuentes con serifa, mismos valores que el linaje web.
  - title: SwiftUI nativo
    details: UI escrita a mano en Swift + SwiftUI puro, sin runtime JS, UI declarativa de primera clase, integración SPM en un clic.
